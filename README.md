# Origami Diagram Maker

A desktop program for making step-by-step origami diagrams from crease patterns.

Downloads will be published under [Releases](https://github.com/origamidiagrammaker/origamidiagrammaker.github.io/releases)
with the first public release. The website is at
<https://origamidiagrammaker.github.io/>.

This repository holds the website and the release downloads only; the program's source code is
not public. The licence terms will be published with the first release.
